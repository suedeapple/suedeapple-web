My Timeline

Before 2026

The Story So Far (more to come)

25+ years building websites and 15+ years specialising in Umbraco CMS, including earning the Umbraco Certified Master accreditation and racking up 275+ posts and 702+ karma points helping others on the Our Umbraco community forum. Full milestone-by-milestone history coming soon.

April–May 2026

Built csswind

Created csswind, a terminal-styled quiz app for learning CSS and Tailwind — ten rapid-fire questions per round, translating between CSS properties and their Tailwind classes.

May–July 2026

Upgraded the Clean Starter Kit for Umbraco to v18

Sent a series of merged pull requests upgrading the headless implementation of Paul Seal's Clean Starter Kit for Umbraco to Umbraco 18 — including mobile navigation fixes, image and cache handling improvements, a sitemap update, and dependency upgrades.

June 2026

Fixed navigation and refactored CSS for High Five You Rock

Merged pull requests fixing a mobile navigation z-index bug and refactoring the CSS for H5YR, the Umbraco community's peer-recognition platform.

June–July 2026

Built three Umbraco.Automate integrations

Released Pushover, ntfy and WeatherAPI connectors for Umbraco.Automate, letting editors trigger push notifications and pull live weather data straight from the back office.

July 2026

Featured on the official Umbraco blog

Named in Umbraco's "Launching Umbraco Automate" blog post for building the Pushover connector, which lets Umbraco Automate send instant push notifications straight to your phone.

June 2026

Documentation fix for UmbracoDocs

Merged a pull request correcting the instructions for creating an automation in the official Umbraco documentation.

June 2026

Credited on Owain Williams' blog

Mentioned on owain.codes for helping work out how to build a publish-triggered Umbraco Automate workflow.

July 2026

UI update for the Bluesky Umbraco.Automate connector

Merged a pull request updating the UI and README for Umbraco 18 on the Bluesky connector for Umbraco.Automate.

July 2026

UI update for the LinkedIn Umbraco.Automate connector

Merged a pull request enhancing the UI for sending a post on the LinkedIn connector for Umbraco.Automate.

July–August 2026

Built three more Umbraco.Automate integrations

Followed up with QR code, Clockify and Brickset connectors for Umbraco.Automate — covering QR generation, time tracking, and even pulling LEGO set data.

Gave an impromptu presentation at the Umbraco Kent Meetup showcasing the Umbraco.Automate plugins built this year — Brickset, Pushover, Clockify, ntfy and more.

Joined "Diving into Umbraco Automate", the US Umbraco meetup group's session on Umbraco Automate, contributing input from the floor.

Merged a pull request adding Umbraco 18 support to the AWS S3 media storage provider for Umbraco.
